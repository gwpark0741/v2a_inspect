Analyze this video in two steps.

**Step 1: Split the video into scenes.**

Scene Definition:
A new scene starts when: location changes, main subject changes, or camera angle drastically changes.

For each scene, determine:
- **scene_index**: 0-based index
- **time_range**: start and end time (0.1s precision, e.g., 3.2, 7.8)

Example scene split for a 10-second video:
- Scene 0: 0.0s - 3.5s (two people talking in a room)
- Scene 1: 3.5s - 7.2s (cut to outdoor street)
- Scene 2: 7.2s - 10.0s (close-up of a car)

**Step 2: For each scene, identify all sound-producing objects.**

For each scene provide:

1. **background_sound**: Continuous environmental/atmospheric sound only.
   - Must NOT include sounds from objects below.
   - Example: "steady rain on glass with distant thunder, muffled café chatter"

2. **objects**: ALL sound-producing objects in the scene. NO COUNT LIMIT.
   Focus on identifying WHAT is making sound, not individual events.
   Rules:
   - Only list an object if it makes a distinct, identifiable sound.
   - If there are no specific sound-producing objects, leave this list empty.
   - Include a specific count (e.g., "a person running", "two swords clashing")
   - For each object:
     **description**: Precise sound the object produces (material, action, intensity, texture)
     **time_range**: time span when this object is actively producing sound (0.1s precision)
     **event_timestamps**: individual impact/onset moments within time_range
       - Repetitive impacts: list each time point
       - Continuous sound: [{"time": <start>, "type": "continuous_start"}]
       - Single impact: [{"time": <T>, "type": "onset", "intensity": "loud"}]
       - type: "onset" | "accent" | "continuous_start"
       - intensity (optional): "soft" | "medium" | "loud"

**Example objects for a scene:**
[
  {
    "description": "a person in high-heels walking on marble tile, sharp rhythmic clicks",
    "time_range": {"start": 0.9, "end": 4.5},
    "event_timestamps": [
      {"time": 1.2, "type": "onset", "intensity": "loud"},
      {"time": 1.8, "type": "onset", "intensity": "loud"},
      {"time": 2.4, "type": "onset", "intensity": "loud"}
    ]
  },
  {
    "description": "a heavy wooden door slamming shut with metallic latch click",
    "time_range": {"start": 4.2, "end": 4.8},
    "event_timestamps": [{"time": 4.2, "type": "onset", "intensity": "loud"}]
  }
]

Rules:
- event_timestamps MUST be within time_range (±0.1s tolerance)
- Mutual Exclusion: background_sound must not overlap with sounds described in objects.
- Every object description MUST contain a specific number/count.
- Object time_range must be within the scene's time_range.
- **Dynamic Selection**: Provide 0 or more objects based on actual video content.
